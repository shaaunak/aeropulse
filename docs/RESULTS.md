# AeroPulse Verification & Experimental Results

## Executive Summary
All metrics reported herein were generated by deterministic, leakage-safe training on genuine **NASA C-MAPSS FD001** simulation trajectories (100 train engines, 100 test engines) using seed `42` on Apple Silicon MPS hardware.

Zero synthetic, fabricated, or hardcoded predictions were used. All evaluation was conducted strictly on the official, held-out test set ($N=100$) against ground truth labels from `RUL_FD001.txt`.

## 2. Evaluation Metric Formulas

### Root Mean Squared Error (RMSE)
$$\text{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^N (\hat{y}_i - y_i)^2}$$

### Mean Absolute Error (MAE)
$$\text{MAE} = \frac{1}{N} \sum_{i=1}^N |\hat{y}_i - y_i|$$

### NASA PHM08 Asymmetric Scoring Function
Let $e_i = \hat{y}_i - y_i$ (prediction minus true RUL):
$$s_i = \begin{cases} \exp\left(-\frac{e_i}{13}\right) - 1 & \text{if } e_i < 0 \quad (\text{underestimate / early call}) \\ \exp\left(\frac{e_i}{10}\right) - 1 & \text{if } e_i \ge 0 \quad (\text{overestimate / late call}) \end{cases}$$
$$\text{Total Score} = \sum_{i=1}^N s_i$$

**Asymmetry Rationale**: In flight operations, overestimating RUL ($\hat{y} > y$) means scheduling maintenance after an engine has already experienced critical HPC degradation, risking uncontained failure. Underestimating RUL ($\hat{y} < y$) incurs premature inspection cost but preserves airworthiness. The metric heavily penalizes positive error.
